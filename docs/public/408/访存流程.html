参考：部件功能与结构

MMU

功能 地址翻译与访问保护。

组成/依赖 地址拆分逻辑、权限检查、TLB、页表遍历硬件（在本模型中）。

检查过程 从 VA 提取 VPN；查 TLB 或遍历页表；检查有效性和权限；拼接 PPN + 页内偏移。

TLB（快表）

功能 缓存最终 VPN → PPN 翻译结果。

组成 VPN 标记、PPN、有效位、权限、地址空间标识等。

比对 本例为全相联：VPN（含地址空间上下文）与所有有效表项并行匹配；不存完整物理地址。

二级页表

功能 保存权威虚拟页映射，按需分配页表页。

组成 页目录（PDE）→ 二级页表（PTE），表项有存在位、页框号、权限等。

定位 页目录基址 + 一级索引×4；二级页表基址 + 二级索引×4。

Cache（数据缓存）

功能 缓存数据的 64 B 物理块。

组成 256 行；每行含数据、Tag、有效位、脏位。

比对 物理地址 Index 定位行；要求 V=1 且 Tag 相等；Offset 选择块内字节。

明确三种“缺失”：TLB miss → 查页表；Cache miss → 向下一级取数据块；Page Fault → CPU 进入操作系统异常处理。三者不能等同。

参考：缺失与异常处理
事件触发条件处理者如何继续
TLB 未命中VPN 没有匹配的有效 TLB 表项本模型：MMU 硬件页表遍历遍历成功，缓存 VPN→PPN；否则异常
PDE/PTE 不存在存在位 P=0CPU 触发 Page Fault；OS 判断原因合法则分配页表/页面或调页后重试；非法则报告错误
访问越权读/写/执行权限或特权级不满足CPU 报告保护故障；OS 处理可恢复的 COW 等修复后重试；否则报告错误
Cache 未命中行无效或 Tag 不匹配缓存控制硬件获取下一级的数据块，更新 Cache
脏块替换Tag 不匹配且旧行 D=1缓存控制硬件确保旧块写回，再复用缓存行
缺页且无空闲物理页框合法页面需要驻留OS 页面置换机制选牺牲页，必要时写回，装入目标页，重试指令

边界问题：32 位地址能表达并不代表进程有权访问。页式系统通常通过有效映射和权限检查识别非法访问，而不必为每次访存使用传统“基址 + 界限”寄存器。Page Fault 本身也不等于一定要磁盘 I/O。
