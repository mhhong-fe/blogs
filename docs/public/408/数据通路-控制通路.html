③ 数据通路 vs 控制通路

数据通路（Datapath）

由寄存器、总线、ALU、多路选择器、暂存器等组成，负责传送、暂存和加工数据。

PC → 内部总线 → MAR
M[MAR] → MDR → 内部总线 → IR

图中蓝色流向表达的数据移动是真正发生在硬件之间的比特传输。

控制通路（Control Path）

由控制单元 CU、指令译码逻辑、时序逻辑和控制信号线构成，负责决定在何时允许哪些部件工作。

IR / FR / 时序状态 → CU → 各控制信号

CU 不需要把整个操作数通过控制线送给 ALU，而是控制 ALU 的操作类型、寄存器读写和总线选通。

同一个周期可以让一个部件驱动单总线、另一个部件接收数据；不能让两个不同来源同时驱动同一条单总线。控制信号可以同时为多个不冲突的部件使能。

⑤ 为什么本题取指没有 MDRin？

题目给出的专门定义：
MDRin 表示内部总线上的数据写入 MDR；MDRout 表示 MDR 内容送内部总线。

取指时，数据不是从 CPU 内部总线送入 MDR，而是由主存通过存储器数据通道送入 MDR。因此不需要触发题目定义的 MDRin。

取指：主存 → MDR（Read）
写存：内部总线 → MDR（MDRin）

但是要注意：“不用 MDRin”不等于“MDR 不需要装入动作”。主存数据仍必须被 MDR 接收；只是这个接收动作由存储器接口的读操作及配套时序负责，和本题的内部总线 MDRin 不是一回事。

如果另一本教材的 MDRin 定义不同呢？

若教材把 MDRin 定义为 MDR 的统一写入使能（包括主存侧数据），那么主存读完成时也可能需要 MDRin。微操作 MDR ← M[MAR] 不变，变化的是硬件控制信号的命名及电路连接。本题要严格依据其文字定义作答。

⑥ 真题第（4）问：取指时序

本题的标准控制信号顺序（不考虑 PC 自增）：

① PCout, MARin
② Read（主存读取到 MDR）
③ MDRout, IRin
阶段主要事情用时
①PC 经单总线送入 MAR1 周期
②发 Read，主存读出并传到 MDR5 周期
③MDR 经单总线送入 IR1 周期
最少 = 1 + 5 + 1 = 7 个时钟周期

注意这是本题给定操作顺序与时序条件下的答案。不要将“3 个微操作阶段”误读为“3 个周期”，也不要随意把 Read 并入第一步来压缩真题标准答案。

⑦ 其他两问一起串联

GPRs：MUX 和地址译码器

rs、rd 为 4 位编号，最多可指定 16 个通用寄存器，两者均从 IR 的指令字段提取。

MUX（多选一）：按 rs 选择哪个寄存器的值输出；地址译码器（译码选通）：按 rd 生成哪一个寄存器的写使能。因此 rd 接地址译码器。

暂存器 Y / Z 为什么存在？

单总线一次只能承载一路数据。Y 先保存 ALU 的一个输入操作数；ALU 运算完成后，Z 保存结果，等待总线空闲后再写回。

FR 和 CU 的关系

ALU 产生 SF/OF 等标志存到 FR；CU 使用 IR 的操作码和 FR 的状态决定后续操作。16 位补码运算下：

SF = F₁₅
加法 OF = ¬(A₁₅ ⊕ B₁₅) ∧ (A₁₅ ⊕ F₁₅)
减法 OF = (A₁₅ ⊕ B₁₅) ∧ (A₁₅ ⊕ F₁₅)

⑧ 需要区分的三个层次

从实际执行一次 ADD R1, R2 看，三个层次分别在做什么：

  1. 指令级：从程序角度看，执行一条 ADD 指令。
  2. 微操作级：选择源寄存器、将一个操作数存入 Y、ALU 运算并存 Z、结果写回寄存器。
  3. 控制信号级：CU 根据操作阶段发出寄存器输出使能、Yin、ALUop、Zin、Zout、寄存器写使能等。
考试作答时，先写微操作的数据流向，再将每一步翻译成来源 out + 目的 in 的控制信号。遇到主存访问，记得区分 CPU 内部总线和主存的数据通道。
“CPU 既是控制者又执行数据搬运”是不是矛盾？

不矛盾。CPU 内的 CU 负责控制，其余寄存器、ALU、内部总线等硬件执行数据传送和运算。对于主存 I/O，还会涉及存储器接口、控制器等部件；不要把整个 CPU 等同于 CU。
